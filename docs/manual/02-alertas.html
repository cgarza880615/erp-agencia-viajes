Módulo 2

🔔 Alertas

Todo lo que necesita acción hoy, en una sola lista. Si tienes que revisar una sola pantalla cada mañana, es esta.

Tipos de alerta que vas a ver

AlertaCuándo aparece
🚨 Pago a proveedor vencidoLa "Fecha límite al proveedor" del itinerario ya pasó y todavía hay deuda pendiente con ese proveedor.
⏰ Pago a proveedor en N díasFaltan 7 días o menos para la fecha límite al proveedor.
🛑 Pago de cliente atrasadoUna parcialidad del plan de pagos tiene fecha programada ya vencida.
⚠️ Check-in pendienteFaltan 3 días o menos para la salida y no se ha marcado el check-in de ida.
💸 Deuda post-viajeEl viaje ya regresó y el cliente todavía debe saldo.
Tip Cada alerta tiene un botón "Ver →" que te lleva directo al itinerario correspondiente — no hace falta buscarlo manualmente en Itinerarios.
Importante Las alertas de proveedor de reservas que pertenecen a un Grupo de Viaje no aparecen aquí a nivel individual — ese control se hace desde el detalle del grupo, para no duplicar la misma alerta una vez por cada pasajero del grupo.
