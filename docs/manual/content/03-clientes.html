Módulo 3

👥 Clientes

La base de datos de todas las personas que han viajado o cotizado con la agencia.

Registrar un cliente nuevo

  1. Da clic en "+ Nuevo Cliente"arriba a la derecha.
  2. Llena nombre completo (único campo obligatorio) — el ID se asigna solo (ej. AC-139).
  3. Teléfono y correo son opcionales, pero captúralos si los tienes — se usan para enviar recibos y para detectar si el cliente ya existe.
  4. Guarda con "Registrar Cliente".
Tip Si el teléfono, correo o nombre ya se parecen mucho a los de un cliente existente, el sistema te avisa antes de guardar, para no crear un cliente duplicado.

Detalle del cliente

Al entrar a un cliente ves su historial completo: cuántos viajes ha hecho, cuántos tiene activos, su gasto histórico, y si está "Al corriente" o tiene deuda activa.

Viajeros frecuentes

Son las personas que suelen viajar junto con este cliente (hijos, pareja, etc.). Una vez agregados aquí, aparecen como sugerencia con un clic al crear un nuevo itinerario para ese cliente — no hay que volver a escribir sus datos cada vez.

❓ Preguntas Frecuentes

El sistema me avisó de un posible duplicado, ¿qué hago?

Revisa el nombre/teléfono/correo que te muestra como coincidencia. Si es la misma persona, mejor usa su ficha existente en vez de crear una nueva (así no se le parte el historial de viajes). Si de verdad es alguien distinto que solo comparte datos parecidos, puedes forzar el guardado.

¿Puedo fusionar dos clientes que quedaron duplicados por error?

No hay un botón para fusionarlos — si ya se duplicó, pide que un administrador lo revise directamente en la base de datos. Por eso conviene revisar bien el aviso de duplicado antes de forzar el guardado.
