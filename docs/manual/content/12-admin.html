⚙️ Admin

Configuración del sistema, usuarios y métricas de rentabilidad — visible solo para cuentas con rol Admin.

Usuarios

RolPuede
AdminTodo: cancelar reservas, marcar incobrables, gestionar usuarios, ver Auditoría.
OperadoraOperación diaria: crear/editar itinerarios, cobros, pagos a proveedor, cotizaciones.
Contraseñas Al crear un usuario o restablecer una contraseña, el sistema exige una contraseña que cumpla los requisitos mínimos de seguridad y guarda el historial — no deja reutilizar una de las últimas usadas.
Nota Nadie puede cambiarse el rol a sí mismo — evita que una cuenta se auto-otorgue permisos por error.

Métodos de Pago

Lista actual: Efectivo, Transferencia, Tarjeta de Crédito/Débito, Depósito bancario y Cheque. Se simplificó a propósito — antes existían entradas separadas para PayPal, Stripe y OXXO Pay que en la práctica nunca se usaban y solo generaban confusión al elegir.

Rentabilidad

Vista consolidada de utilidad del negocio, separando lo ya cobrado (utilidad real) de lo proyectado sobre reservas aún no liquidadas — útil para decisiones de negocio, no para el día a día operativo.

❓ Preguntas Frecuentes

¿Por qué no me deja cambiar mi propio rol?

Es intencional: ningún usuario puede cambiarse el rol a sí mismo, para evitar que una cuenta se auto-otorgue permisos de administrador por error o sin supervisión. Pide a otro admin que lo haga por ti.

¿Por qué el sistema rechaza la contraseña que quiero poner?

Debe cumplir los requisitos mínimos de seguridad (longitud y complejidad) y no puede ser una de las últimas contraseñas ya usadas por ese usuario — el sistema guarda ese historial para evitar reciclarlas.
