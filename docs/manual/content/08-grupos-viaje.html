🧳 Grupos de Viaje

Para cuando muchas personas (10, 20, 30+) viajan juntas al mismo destino con el mismo paquete base — en vez de manejar el presupuesto por cada itinerario individual, se maneja una sola vez a nivel de grupo.

Crear un grupo

  1. Nombre del grupo (ej. "Cancún Fin de Año 2026") y destino.
  2. Cupos bloqueados: cuántos lugares se reservaron con el proveedor, aunque no se hayan vendido todos todavía.
  3. Precio del paquete base por pax y % de margen deseado — el sistema calcula la utilidad esperada por pasajero.
  4. Crea el grupo — el presupuesto por categoría y la logística compartida (hotel, vuelos, traslados, tours) se agregan después, desde el detalle del grupo.

Cómo se relaciona con los Itinerarios

Al crear un itinerario individual, puedes asignarlo a un grupo existente desde el propio formulario de creación. El costo del paquete se prorratea automáticamente entre las reservas del grupo, según el número de pasajeros de cada una.

Nota El pago a proveedor de un grupo se registra una sola vez, a nivel de grupo — nunca por cada itinerario individual. Así se evita pagarle al mismo proveedor varias veces por error, una por cada familia del grupo.

❓ Preguntas Frecuentes

Se agregó una familia más al grupo después de aplicar el prorrateo, ¿qué hago?

Vuelve a dar clic en "Aplicar prorrateo" — recalcula el costo repartido entre todas las reservas vinculadas al grupo en ese momento, incluyendo la nueva.

¿Por qué el costo de un pasajero individual cambió sin que yo lo tocara?

Probablemente alguien aplicó de nuevo el prorrateo del grupo (por ejemplo al agregar o quitar una reserva) — el costo por pasajero siempre se recalcula sobre el total del grupo entre el número de pasajeros vigente en ese momento.
